  `https://sqms.kspo.or.kr/exam/wrStandard.kspo`
- **조회일**: 2026-08-04
- **자격제도안내(과목 구성 확인)**: `https://sqms.kspo.or.kr/info/licenseInfoHexm.kspo`
- **용도**: 콘텐츠 재편 시 `courses`(단원) 경계·명칭의 정본
- **주의**: KSPO 출제기준 페이지는 해당 과목을 `병태심리학`으로 표기하고 있으나,
  자격제도안내 페이지 및 실제 과목명은 `병태생리학`이다. KSPO 측 표기 오류로 판단하며
  본 문서와 DB는 `병태생리학`으로 통일한다.

## 시험 개요

- 필기 8과목 전부 필수 (선택 없음)
- 합격 기준: 과목마다 만점의 40% 이상 + 전 과목 총점 60% 이상
- 취득절차: 필기 → 실기·구술 → 연수(200시간)
- 실기·구술 검정내용: 심폐소생술(CPR)/응급처치, 건강·체력측정평가,
  운동트레이닝방법, 운동손상 평가 및 재활
