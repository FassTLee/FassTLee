## 1. 문서의 목적과 범위

이 문서는 Kinepia의 필기 자격증 콘텐츠를 어떤 구조로 지을 것인지 정한다. 단원(course) 경계와 명칭, 챕터 수 배분, 그 판단의 근거를 담는다.

**범위에 포함**: 단원 구성, 챕터 배분, 명칭 규칙, 콘텐츠 생성 원칙, 도해 조달 방침, 데이터 보강 계획, 교차검증 계획
**범위 밖**: 개별 챕터의 내용 설계, DB 마이그레이션 절차, 화면 구현

**범위 밖 과목**: 특수체육론·유아체육론·노인체육론(2급, 장애인·유소년·노인 스포츠지도사 필수과목)은 2급 생활스포츠지도사 출제기준 7과목에 포함되지 않는다.

## 2. 앵커 원칙

1. **국가 출제기준의 주요항목** — 정본: `https://sqms.kspo.or.kr/exam/wrStandard.kspo`

## 4. 단원 구성 규칙

### 4.1 기본 원칙

**단원(course) = 출제기준 주요항목 1:1**이 원칙이다. 학습자가 출제기준과 직접 대조할 수 있어야 한다.

### 4.2 분할 판정 기준

주요항목의 출제 비중과 **내부 구조의 성격**으로 판정한다. v1.0은 비중만으로 판정했으나, 15과목을 거치며 비중만으로는 설명되지 않는 사례(운동부하검사·운동상해·운동처방론)가 확인되어 4.2.1을 추가한다.

| 비중 | 1차 판정 |
|---|---|
| **26% 초과** | 분할 검토 대상 |
| 20% 초과 ~ 26% 이하 | 시판 교재 3종 중 2종 이상이 분리한 경우에만 분할 |
| 20% 이하 | 분할하지 않음 |

#### 4.2.1 단일흐름 예외 (v1.1 신규)

26%를 초과해도 아래 조건을 **모두** 충족하면 분할하지 않고 **챕터 수만 확장**한다(4.4.1 참조).

1. 내부가 절차·단계의 연속(준비→시행→종료 등) 또는 대상자·유형별 반복 패턴으로 구성되어 있다
2. 분할하면 같은 방법론·기법이 여러 단원에 중복 배치된다
3. 학습 순서가 그 흐름을 따라야 이해가 성립한다

**확인된 사례**
- 운동부하검사 — 수행(31%): 준비→시작→모니터링→종료의 단일 절차
- 운동상해 — 관리 기술(30%): 검사·평가 기법이 부위를 가리지 않고 공통 적용
- 운동처방론 — 특수대상자(49%): 대상자 유형별로 반복되는 동일 학습 패턴(질환 특성→금기사항→권장 강도)

반대로 **부위별·계통별로 이질적인 내부 구조**는 그대로 분할한다(한국체육사 근·현대, 기능해부학 근골격계, 건강·체력평가 체력검사, 병태생리학 심혈관계, 스포츠교육학 지도방법론, 스포츠심리학 2개 항목).

- 분할 시 내부 구분과 각 단원의 챕터 수는 **세부항목별 비중 실측**에 따른다. 균등 분할하지 않는다.
- 교재 분리 여부는 목차 원문으로 판정하고, 판정 근거를 해당 과목 절에 남긴다.

### 4.3 병합 판정 기준

비중이 낮아도 **주요항목을 병합하지 않는다.** 병합하면 출제기준 명칭이 사라져 학습자의 대조가 불가능해진다. 하한 미달 구간은 챕터 하한 5를 배정한다.

**예외**: 공유 과목에서 상속받은 과목(10절)은 상속원(2급)에 없던 항목이 대상 자격증에서 0%로 확인돼도 단원을 유지하되, 콘텐츠는 상속원 것을 그대로 쓴다(신규 제작 없음).

### 4.4 챕터 수 산정

단원당 **5~12챕터**. 비중에 따라 아래 표로 산정한다.

| 비중 | 챕터 |
|---|---:|
| 6% 미만 | 5 |
| 6~10% | 6 |
| 11~14% | 7 |
| 15~17% | 8 |
| 18~20% | 10 |
| 21~23% | 11 |
| 24~26% | 12 |

- 26% 초과 구간은 4.2에 따라 분할되므로 이 표에 나타나지 않는다. 단, 4.2.1 단일흐름 예외는 4.4.1을 따른다
- 하한 5는 비중과 무관하게 보장한다

#### 4.4.1 단일흐름 예외의 챕터 상한 초과 (v1.1 신규)

4.2.1에 해당하는 단원은 상한 12를 넘겨 배정할 수 있다. 초과분은 내부 하위 대상·단계의 개수에 비례한다.

**확인된 사례**: 운동처방론 특수대상자(49%) — 대상자 유형이 10개 이상이라 12챕터로 물리적으로 담기지 않는다. **20챕터**로 배정.

이 예외는 남용 방지를 위해 **26% 초과 + 4.2.1 조건 충족**의 경우로 한정한다. 그 외 상한 초과는 인정하지 않는다.

**이 배분은 출제 빈도 기반이며 학습 분량 기반이 아니다.** 세부항목 매핑 완료 후 재조정 대상으로 둔다. 교재 페이지 수를 대조군으로 쓸 수 있다(부록 C).

## 5. 명칭 규칙

- **단원 명칭은 출제기준 명칭을 축약·의역 없이 그대로 쓴다.**
- 분할 단원은 `{상위 주요항목명} — {세부 구분}` 형식으로, 상위 명칭을 반드시 남긴다.
  - 예: `한국 근·현대 — 개화기`, `근골격계 — 상지`
- 자격증 명칭은 정식 명칭을 쓴다. 데이터(파일명·`cert` 필드·slug)에 약칭을 넣지 않는다.
  - `건강운동관리사`(국가) / `운동건강관리사`(민간)는 별개 자격증이다. 혼동 사고 이력 있음(T27).

민감도·특이도 기반 가양성/가음성 인원 계산, 예측도, 에너지소비량, 목표심박수 등 수치 계산이 반복된다.
**관리 규칙**: 콘텐츠 설계 시 계산 문제 전용 UI(단계별 풀이 노출)를 검토한다.

**우선 조사 대상 1순위로 지정.** 문자열 매칭이 아니라 **문항 내용 기반 판독**(개념이 해부학적 위치를 전제하는지)이 필요하며, 이는 문항–세부항목 매핑 작업과 함께 수행하는 것이 효율적이다(12절).

### 11.1 기출 문항 취급 — 전량 재생성

기출 원문을 그대로 카드화하지 않는다. 6개년(확보 시) 출제 경향 분석을 바탕으로 **재생성**한다.

|---|---|---|

**신규가 가장 위험하다.** 근거 대장이 반드시 작동해야 하는 구간이다.

### 11.2 생성 소스

| 소스 | 지위 | 용도 |
|---|---|---|

| 공개 학술자료 | 인용 가능 | 개념 설명의 근거 |

**상용 교재 취급 (오너 결정)**: 권리 미확보 상태로 1차 서비스에 포함. 3종 교차 참조 → 공통분만 채택 → 원문 없이 재작성. **델파이 판정 이력의 입력본에는 교재 원문을 넣지 않는다**(특허 2 실시 증거). 교재 페이지 인용 표기 금지.

모든 사실 주장은 출처와 함께 등재. 미등재 문장은 생성 게이트에서 차단. 항목: 사실 진술 / 출처 / 관련 세부항목 / 등재일.

### 11.4 검수 체크리스트

「콘텐츠 검수 체크리스트 v0.9(잠정)」 별도 문서. 축 1(권리 안전성)·축 2(사실 정확성·문항 정합성) 0건 게이트. **축 3(출제 적합성)은 문항–세부항목 매핑 완료 후 확정.**

### 11.5 이중화 검증 대상 (콘텐츠 생성 단계)

## 13. CX 교차검증 계획

### 13.1 배경

### 13.2 대상 1 — 문항–세부항목 귀속의 독립 재현 (최우선)

**문제**: 15과목 1,320문항(2급 700 + 건운사 620, 미확보분 제외)의 주요항목 귀속은 **PM(Claude) 단독 판단**으로 수행됐다. 문두 패턴, 위치 규칙, concept/keywords만을 근거로 했고, 제3자 검증이 없었다. 챕터 배분 전체가 이 귀속 위에 서 있다.

**방법**: 과목당 표본 20문항(전체의 20%, 약 264문항)을 CX에 전달하되 **PM의 기존 귀속 결과를 알리지 않고**, 같은 attribution 파일과 출제기준 주요항목 목록만 제공해 독립적으로 분류하게 한다. PM이 합집합·불일치를 대조한다.

**판정 기준**: 일치율 90% 이상이면 PM 귀속을 신뢰. 특정 과목에서 불일치가 집중되면 그 과목 전수 재검토.

**우선순위**: 판정선 근접 과목(2급 운동생리학 골격근 20%, 건운사 기능해부학 인체역학 25%, 건운사 스포츠심리학 확장형 판정의 근거가 된 항목들)을 표본에 반드시 포함한다.

### 13.3 대상 2 — 정답 키 이중 추출의 확대 (진행 중 항목의 완료)

**현황**: CC-07이 건강운동관리사 2021 정답 키 160셀을 좌표 파싱(d) vs 육안 판독(e)으로 이중 대조해 **불일치 0건**을 확인했다. 나머지 연도·자격증은 미수행 상태로 남아 있다(CC-07 우선순위 목록 참조).

**방법**: 같은 방식을 CX에 동일 발주해 CC와 별도로 재현한다. 이미 CC가 검증한 2021년분도 CX로 재확인하면 방법 자체의 신뢰도가 오른다.

**대상**: 건운사 2022~2024(6키) → 2급 2022(과목 순서 상이 이력) → 나머지 순.

### 13.4 대상 3 — 도해 문항 규모 재산정 (파괴적 작업 전 판정 성격)

**문제**: 9절의 도해 규모는 문자열 매칭 하한값이며, 재현율 20%로 확인됐다. 도해 제작은 디자이너 채용·외주 등 비용이 큰 결정이라 규모 오판의 영향이 크다.

**방법**: CC와 CX에 동일하게 "1,320문항 중 그림·표·도식을 필요로 하는 문항 판정"을 발주하되, CC는 기존 렌더·판독 결과 기반으로, CX는 stem 텍스트 내용 분석(문맥상 시각 자료 없이 풀이 불가능한 문항 식별)으로 독립 수행한다. 두 결과의 합집합을 최종 규모로 삼는다.

**우선 대상**: 운동상해(9.2절에서 지목한 재산정 필요 과목).

### 13.5 실행 순서

## 14. 데이터 무결성 전제

- **모든 slug는 URL 진입점에서 UUID로 변환**한다. `chapter_stats.chapter_id`는 FK 없는 text이므로 slug 유입 시 특허 1 행동 분류 데이터가 오염된다.
- **`course : certification = 1:1` 복제 유지.** admin 권한 모델의 scope 경계 전제이기도 하다.
- 기존 courses/chapters는 `is_active = false`로 비활성화. **DELETE 금지.**
- 신규 course 생성 시 `course_certifications` 매핑까지 한 트랜잭션으로.

- `courses.exam_type` 28행 전부 NULL — course 계층에 필기/구술/실기 구분 수단 없음
