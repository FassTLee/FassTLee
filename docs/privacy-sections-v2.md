### 삭제 사유

| 문구 | 사유 |
|---|---|
| IP 주소 AES-256 암호화 저장 | IP를 저장하는 컬럼은 `landing_test_sessions.ip_address` 하나이며 해당 경로는 호출부 0건·0행. 실제로 IP를 저장하지 않음 |
| AES-256-GCM 암호화 (이메일·IP) | 위와 동일. `crypto.ts` 호출부 1곳뿐이고 그 라우트가 미사용 |
| 회원 탈퇴 시 즉시 삭제 (30일 이내) | FK 제약으로 `profiles` 삭제가 거부됨. 현재 접수 후 순차 처리 상태 |
| 학습 데이터는 탈퇴 요청 즉시 비식별화 처리 | 비식별화 구현 없음. 안 A 트랙 완료 후 v3에서 재기재 |
| Google AdSense | 스크립트 로드 코드 0건. 현재 카카오 애드핏만 사용 |

### 학습 데이터 표현 — 범주 수준 유지

특허 임시명세서(10-2026-0098736)의 청구범위가 미제출 상태이므로, 관측 신호를 나열하지 않고 범주 수준으로만 기재합니다. 체류시간·클릭 간격·재방문·오답 후 행동 등 개별 측정 신호는 방침에 넣지 않습니다.

## 3. 배열 밖 수정 항목 3건

SECTIONS 배열에 포함되지 않아 별도로 수정해야 합니다.

### (1) 인트로 문단 — L146 부근

```
현행: 본 방침은 Google OAuth를 통해 수집되는 정보와 서비스 이용 중 생성되는
      학습 데이터의 처리 방법을 설명합니다.

교체: 본 방침은 소셜 로그인(구글·카카오·네이버)을 통해 수집되는 정보와

```

### (2) 처리 기간 — L186 부근


사유: 5일 이내 처리를 보장할 절차가 없습니다. 접수 기록 테이블 도입 후 재기재합니다.

## 4. 미확인 항목 2건

교체본에 반영했으나 실측되지 않은 사항입니다. 배포 전 확인이 필요합니다.

| 항목 | 상태 |
|---|---|
| Rate Limiting 실제 임계값 | 기존 문구 "분당 60회"가 `middleware.ts` 구현과 일치하는지 미확인. 교체본에서는 수치를 빼고 서술형으로 처리 |
| `AdBanner` 조건부 AdSense 코드 | `NEXT_PUBLIC_AD_MODE === 'adsense'`일 때 렌더되는 코드가 남아 있음. 환경변수가 실제로 무엇인지 미확인. `adsense`로 설정돼 있으면 방침과 불일치 |
